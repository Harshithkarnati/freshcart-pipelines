

# FreshCart Pipelines

Data Engineering assignment: From Git to Gold.

## Project Overview

This project demonstrates an end-to-end data engineering
workflow involving:

1. Git and CI/CD using GitHub Actions.
2. FreshCart ELT pipeline using Snowflake.
3. Machine Learning pipeline using Mage.
4. Real-time food-order streaming using RabbitMQ.

## Project Structure

- elt/: FreshCart ELT notebook
- iris_project/: Mage Iris ML pipeline
- stream/: RabbitMQ dispatcher and driver
- tests/: Python unit tests
- .github/workflows/: GitHub Actions CI configuration

## Technologies

Python, Git, GitHub Actions, Snowflake, Mage,
RabbitMQ, Pandas and Scikit-learn.
